# Pegasus menu for kiosk mode. Each tile runs `kiosk run <id>` (~/.local/bin/kiosk).
# To add a tile: copy a block, pick a new kiosk:<id>, and add that <id> to the
# `run` case in the script. Pegasus ignores entries without a `file:` line.
#
# The first collection is the home screen (theme: ~/.config/pegasus-frontend/themes/kiosk-tv).
# A tile with `x-folder: <collection>` opens that collection as a folder; without
# its own picture it shows the folder's first four tiles. A folder's collection
# goes in its own file (streaming/metadata.pegasus.txt, listed in
# ~/.config/pegasus-frontend/game_dirs.txt), because Pegasus adds every game in a
# file to all the collections defined above it.
# Tiles are ordered by sort-by, compared as text, so keep two digits.
# Images in media/ come from ./make-tiles.
